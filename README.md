# grpc-dc (PHP)

gRPC over WebRTC DataChannels — a generated, dependency-free
PHP runtime (PHP 8.1+, stdlib only): clients and servers
speaking the gRPC wire protocol over a WebRTC DataChannel.

Install: `composer require browser-grpc/grpc-dc`. Kafka
stubs ship separately in the `browser-grpc/kafka-grpc`
package, which depends on this one.
